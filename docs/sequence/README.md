# Sequence-диаграммы

Диаграммы показывают взаимодействие участников в трёх ключевых сценариях. Названия эндпоинтов предварительные и будут уточнены при описании API.

| Файл | Сценарий | Требования | Что показывает |
|---|---|---|---|
| 01-status-update-notification.puml | Агент обновляет статус, клиент получает уведомление | FR-11, FR-12, FR-14, FR-15 | Синхронную запись статуса и асинхронную рассылку через очередь |
| 02-inspection-report-decision.puml | Отчёт об осмотре и решение клиента | FR-06, FR-07 | Загрузку файлов, проверку доступа, ветвление решений |
| 03-claim-submission.puml | Претензия | FR-16 | Бизнес-правило срока 14 дней и решение агента |

## Обозначения

| Стрелка | Значение |
|---|---|
| Сплошная с закрашенным наконечником | Синхронный вызов: отправитель ждёт ответа |
| Сплошная с открытым наконечником | Асинхронное сообщение: отправитель не ждёт ответа |
| Пунктирная | Ответ |
